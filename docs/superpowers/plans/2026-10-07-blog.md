# Blog de la liga — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pestaña pública **Blog** (entre Inicio y Estadísticas) donde cualquiera lee las novedades, y una sección **Blog** en el panel de admin donde un admin sube un `.md`, lo previsualiza, lo deja como borrador o lo publica, y puede despublicarlo, reemplazar su contenido o borrarlo.

**Architecture:** El Markdown se guarda tal cual en Postgres (`tournament.blog_posts`, migración `v12.sql`) — un `.md` es texto, no hace falta Supabase Storage. La API FastAPI expone lectura pública (solo publicadas) y CRUD admin; el extracto para la lista se calcula al escribir. El frontend lo pinta con `react-markdown` + `remark-gfm` **sin HTML crudo** (`skipHtml`), así que el contenido no puede inyectar scripts aunque el `.md` los traiga.

**Tech Stack:** FastAPI + psycopg2 (`BATSDatabase`), Pydantic v2, PostgreSQL/Supabase · React 19, react-router 7, TanStack Query 5, Tailwind 4, Vitest + Testing Library · react-markdown 10.1.0, remark-gfm 4.0.1.

**Spec:** No hay spec aparte: los requisitos salen de la petición del 2026-10-07 («tab de Blog entre Inicio y Estadísticas; los admins suben un .md desde su panel; el usuario normal lo ve en Blog») y de este documento.

## Global Constraints

- Textos de la UI y comentarios en **español** (como el resto del repo).
- Pestaña nueva **«Blog»**, ruta pública `/blog` y `/blog/:slug`, colocada **entre «Inicio» y «Estadísticas»** en la barra superior y en la barra inferior móvil.
- Admin: ruta `/admin/blog`, en el grupo «Comunidad» del menú lateral.
- Límite de contenido: **200 000 caracteres** (`BLOG_MAX_CHARS` en `web/src/lib/blog.ts` y `MAX_CHARS` en `bats_core/blog.py`; deben coincidir). Título: **máx. 160** caracteres.
- Solo `.md` / `.markdown`. El HTML crudo dentro del Markdown **nunca** se renderiza.
- El `slug` se fija al crear la entrada y **no cambia** al editar el título (los enlaces compartidos no se rompen).
- Migraciones idempotentes (`IF NOT EXISTS`), como todas las de `bats_core/db/migrations/`.
- Versiones exactas de dependencias nuevas: `react-markdown@10.1.0`, `remark-gfm@4.0.1`.
- Tests de API con base: `unittest` + `@unittest.skipUnless(DSN, ...)` con `BATS_TEST_DSN`, como `tests/test_admin_players.py`.

## Review Focus

1. **`.md` guardado desde Windows con BOM o CRLF** → el título se detecta igual y no aparece un `﻿` al inicio. (Test en Task 4: `readMarkdownFile` con BOM + `\r\n`.)
2. **`.md` con `<script>`, `<img onerror>` o enlaces `javascript:`** → se muestran como nada / enlace inerte, nunca se ejecutan. (Test en Task 5.)
3. **Dos entradas con el mismo título (o títulos solo con emojis/símbolos)** → slugs distintos y válidos (`novedades`, `novedades-2`; `entrada`). (Tests en Tasks 1 y 3.)
4. **Borradores** → nunca aparecen en `/api/blog` ni en `/api/blog/{slug}`, aunque se adivine el slug; despublicar y volver a publicar conserva la fecha original. (Tests en Task 3.)
5. **El `.md` empieza con `# Título` igual al título de la entrada** → no se ve el título dos veces en la página ni en el extracto. (Tests en Tasks 1 y 4.)

```python
"""
BATS — Utilidades del blog (sin base de datos).

slugify: título → slug estable para la URL (/blog/<slug>). Se calcula una vez al
         crear la entrada y no cambia aunque luego se edite el título.
excerpt: Markdown → texto plano corto para la lista de entradas. Se guarda al
         escribir para que la lista no tenga que leer el contenido completo.
"""
import re
import unicodedata

MAX_CHARS = 200_000   # mismo límite que web/src/lib/blog.ts::BLOG_MAX_CHARS
TITLE_MAX = 160
SLUG_MAX = 100
EXCERPT_MAX = 180


def slugify(title: str) -> str:
    text = unicodedata.normalize("NFKD", title).encode("ascii", "ignore").decode("ascii").lower()
    slug = re.sub(r"[^a-z0-9]+", "-", text).strip("-")
    return slug[:SLUG_MAX].rstrip("-") or "entrada"


# Orden importante: primero lo que contiene otras marcas (bloques de código, imágenes).
_CLEANUP = [
    (re.compile(r"```.*?```", re.S), " "),                       # bloques de código
    (re.compile(r"!\[[^\]]*\]\([^)]*\)"), " "),                  # imágenes
    (re.compile(r"\[([^\]]*)\]\([^)]*\)"), r"\1"),               # enlaces → su texto
    (re.compile(r"<[^>]+>"), " "),                               # HTML
    (re.compile(r"^\s*[-:| ]{3,}\s*$", re.M), " "),              # separadores de tabla / reglas
    (re.compile(r"^\s{0,3}(#{1,6}|>|[-*+]|\d+\.)\s+", re.M), ""),  # marcas de bloque
    (re.compile(r"[*_`~|]"), " "),                               # énfasis, código, celdas
]


def excerpt(markdown: str, title: str = "", limit: int = EXCERPT_MAX) -> str:
    body = markdown
    first = re.match(r"\s*#\s+(.+?)\s*(?:\n|$)", body)
    if first and title and first.group(1).strip().lower() == title.strip().lower():
        body = body[first.end():]   # el H1 inicial suele repetir el título
    for pattern, repl in _CLEANUP:
        body = pattern.sub(repl, body)
    text = " ".join(body.split())
    text = re.sub(r"\s+([.,;:!?])", r"\1", text)   # «vota .» → «vota.» tras quitar el énfasis
    if len(text) <= limit:
        return text
    cut = text[:limit].rsplit(" ", 1)[0]
    return cut.rstrip(" ,.;:") + "…"
```

```sql
-- =============================================================================
-- BATS — Migración v12: blog de la liga
-- =============================================================================
-- Los admins suben un .md desde el panel; se guarda el Markdown tal cual y lo
-- pinta el frontend (sin HTML crudo). `excerpt` se calcula en la API al escribir
-- (bats_core/blog.py) para que la lista no lea el contenido completo.
--
-- is_published = FALSE → borrador: invisible en /api/blog.
-- published_at se fija la PRIMERA vez que se publica y se conserva al despublicar,
-- para que volver a publicar no la mande al principio de la lista.
-- author_username es una firma (snapshot), no una FK: renombrar la cuenta no la cambia.

CREATE TABLE IF NOT EXISTS tournament.blog_posts (
  post_id         SERIAL       PRIMARY KEY,
  slug            VARCHAR(120) NOT NULL UNIQUE,
  title           VARCHAR(160) NOT NULL,
  content_md      TEXT         NOT NULL CHECK (char_length(content_md) <= 200000),
  excerpt         VARCHAR(200) NOT NULL DEFAULT '',
  author_username VARCHAR(50),
  is_published    BOOLEAN      NOT NULL DEFAULT FALSE,
  published_at    TIMESTAMPTZ,
  created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_blog_posts_published
  ON tournament.blog_posts (published_at DESC) WHERE is_published;
```

`bats_core/api/routes/blog.py`:

```python
"""
BATS — Blog de la liga.

Públicos (solo entradas publicadas):
  GET    /api/blog                  → lista: título, extracto, autor, fecha
  GET    /api/blog/{slug}           → entrada completa (Markdown crudo; lo pinta el cliente)

Admin:
  GET    /api/admin/blog            → todas, incluidos borradores
  GET    /api/admin/blog/{id}       → una, con contenido (para previsualizar borradores)
  POST   /api/admin/blog            → crea una entrada desde un .md (borrador o publicada)
  PATCH  /api/admin/blog/{id}       → título / contenido / publicación (el slug no cambia)
  DELETE /api/admin/blog/{id}       → elimina

El Markdown se guarda tal cual: el frontend lo pinta sin HTML crudo
(web/src/components/blog/Markdown.tsx), así que aquí no se sanea.
"""
from fastapi import APIRouter, Depends, HTTPException

from ...blog import excerpt, slugify
from ..auth import require_admin
from ..common import iso
from ..db import get_db
from ..schemas import CreateBlogPostRequest, UpdateBlogPostRequest

def _clean(title: str, content: str) -> tuple[str, str]:
    title = title.strip()
    if not title:
        raise HTTPException(status_code=422, detail="La entrada necesita un título.")
    if not content.strip():
        raise HTTPException(status_code=422, detail="El archivo está vacío.")
    return title, content


def _unique_slug(db, title: str) -> str:
    base = slugify(title)
    taken = {r["slug"] for r in db.fetchall(
        "SELECT slug FROM tournament.blog_posts WHERE slug = %s OR slug LIKE %s", (base, base + "-%"))}
    if base not in taken:
        return base
    n = 2
    while f"{base}-{n}" in taken:
        n += 1
    return f"{base}-{n}"
```

```ts
/** Límites del .md: los mismos que valida la API (bats_core/blog.py). */
export const BLOG_MAX_CHARS = 200_000;
export const BLOG_TITLE_MAX = 160;

const H1 = /^ {0,3}#[ \t]+(.+?)[ \t#]*$/m;

/** Título de una entrada: el primer `# Título` del Markdown o, si no hay, el nombre del archivo. */
export function titleFromMarkdown(markdown: string, filename: string): string {
  const h1 = H1.exec(markdown);
  if (h1) return h1[1].trim();
  return filename.replace(/\.(md|markdown)$/i, "").replace(/[-_]+/g, " ").trim();
}

/** El título ya va en la cabecera de la página: si el .md empieza repitiéndolo, se omite. */
export function stripLeadingTitle(markdown: string, title: string): string {
  const m = /^\s*#[ \t]+(.+?)[ \t#]*(?:\r?\n|$)/.exec(markdown);
  if (!m || m[1].trim().toLowerCase() !== title.trim().toLowerCase()) return markdown;
  return markdown.slice(m[0].length).replace(/^\s+/, "");
}

/** Error presentable al admin tal cual. */
export class MarkdownFileError extends Error {}

/** Lee el .md elegido; rechaza otros formatos, vacíos o demasiado grandes. */
export async function readMarkdownFile(file: File): Promise<{ title: string; content: string }> {
  if (!/\.(md|markdown)$/i.test(file.name)) throw new MarkdownFileError("Elige un archivo .md.");
  // Los editores de Windows a veces guardan con BOM y CRLF.
  const content = (await file.text()).replace(/^﻿/, "").replace(/\r\n?/g, "\n");
  if (!content.trim()) throw new MarkdownFileError("El archivo está vacío.");
  if (content.length > BLOG_MAX_CHARS) throw new MarkdownFileError("El archivo es demasiado grande (máx. 200 000 caracteres).");
  return { title: titleFromMarkdown(content, file.name).slice(0, BLOG_TITLE_MAX), content };
}
```

```tsx
function UploadForm() {
  const { toast } = useToast();
  const input = useRef<HTMLInputElement>(null);
  const [draft, setDraft] = useState<{ title: string; content: string } | null>(null);
  const [fileError, setFileError] = useState<string | null>(null);
  const [view, setView] = useState<"preview" | "source">("preview");
  const create = useBlogMutation(createBlogPost);

  async function onFile(file: File | undefined) {
    if (!file) return;
    setFileError(null);
    try { setDraft(await readMarkdownFile(file)); setView("preview"); }
    catch (err) { setDraft(null); setFileError(err instanceof MarkdownFileError ? err.message : "No se pudo leer el archivo."); }
    finally { if (input.current) input.current.value = ""; }   // elegir el mismo archivo otra vez vuelve a disparar onChange
  }

  async function save(publish: boolean) {
    if (!draft) return;
    try {
      await create.mutateAsync({ title: draft.title.trim(), content_md: draft.content, publish });
      toast({ title: publish ? "Entrada publicada" : "Borrador guardado", tone: "success" });
      setDraft(null);
    } catch (err) { toast({ title: "No se pudo guardar", description: errorMessage(err), tone: "error" }); }
  }

  return (
    <section className="flex flex-col gap-4 rounded-2xl bg-card p-5 shadow-sm ring-1 ring-border">
      <h2 className="text-headline">Nueva entrada</h2>
      <label className="press flex cursor-pointer flex-col items-center gap-2 rounded-2xl border border-dashed border-input px-4 py-8 text-center text-subhead text-muted-foreground transition-colors hover:bg-muted/40 focus-within:ring-2 focus-within:ring-ring">
        <FileUp className="size-6" />
        <span>Elige un archivo <strong className="text-foreground">.md</strong></span>
        <input ref={input} type="file" accept=".md,.markdown,text/markdown" aria-label="Archivo .md" className="sr-only"
          onChange={(e) => void onFile(e.target.files?.[0])} />
      </label>
      {fileError && <p role="alert" className="text-footnote text-destructive">{fileError}</p>}

      {draft && (
        <>
          <div className="flex flex-col gap-1.5">
            <label htmlFor="blog-title" className="text-footnote font-medium">Título</label>
            <Input id="blog-title" value={draft.title} maxLength={BLOG_TITLE_MAX}
              onChange={(e) => setDraft({ ...draft, title: e.target.value })} />
          </div>
          <SegmentedControl label="Vista" value={view} onChange={setView} className="self-start"
            options={[{ value: "preview", label: "Vista previa" }, { value: "source", label: "Markdown" }]} />
          <div className="max-h-[28rem] overflow-y-auto rounded-2xl bg-background p-5 ring-1 ring-border">
            {view === "preview"
              ? <Markdown>{draft.content}</Markdown>
              : <pre className="whitespace-pre-wrap font-mono text-footnote">{draft.content}</pre>}
          </div>
          <div className="flex flex-wrap gap-2">
            <Button onClick={() => void save(true)} disabled={create.isPending || !draft.title.trim()}>
              {create.isPending ? <Loader2 className="animate-spin" /> : null} Publicar
            </Button>
            <Button variant="secondary" onClick={() => void save(false)} disabled={create.isPending || !draft.title.trim()}>Guardar borrador</Button>
            <Button variant="ghost" onClick={() => setDraft(null)} disabled={create.isPending}>Descartar</Button>
          </div>
        </>
      )}
    </section>
  );
}

function PostList() {
  const { toast } = useToast();
  const posts = useAdminBlogPosts();
  const [previewId, setPreviewId] = useState<number | null>(null);
  const [pendingDelete, setPendingDelete] = useState<AdminBlogPost | null>(null);
  const preview = useAdminBlogPost(previewId);
  const update = useBlogMutation((v: { id: number; is_published: boolean }) => updateBlogPost(v.id, { is_published: v.is_published }));
  const del = useBlogMutation(deleteBlogPost);

  async function togglePublished(p: AdminBlogPost) {
    try {
      await update.mutateAsync({ id: p.post_id, is_published: !p.is_published });
      toast({ title: p.is_published ? "Entrada retirada" : "Entrada publicada", tone: "success" });
    } catch (err) { toast({ title: "No se pudo cambiar", description: errorMessage(err), tone: "error" }); }
  }

  if (posts.isError) return <ErrorState error={posts.error} onRetry={() => posts.refetch()} />;
  if (posts.isPending) return <Skeleton className="h-40 rounded-2xl" />;

  return (
    <>
      <Group title="Entradas" footer="Las publicadas se ven en la pestaña Blog; los borradores solo aquí.">
        {posts.data.length === 0 ? <EmptyState title="Sin entradas" description="Sube tu primer .md arriba." /> :
          posts.data.map((p) => (
            <GroupRow key={p.post_id}
              title={p.title}
              subtitle={p.is_published ? `Publicada el ${fmtDate(p.published_at)}` : `Borrador · ${fmtDate(p.created_at)}`}
              leading={<Badge variant={p.is_published ? "success" : "secondary"}>{p.is_published ? "Publicada" : "Borrador"}</Badge>}
              trailing={
                <span className="flex shrink-0 items-center gap-1">
                  <Button variant="ghost" size="sm" onClick={() => setPreviewId(p.post_id)}>Ver</Button>
                  <Button variant="ghost" size="icon" aria-label={p.is_published ? `Retirar ${p.title}` : `Publicar ${p.title}`}
                    disabled={update.isPending} onClick={() => void togglePublished(p)}>
                    {p.is_published ? <EyeOff /> : <Eye />}
                  </Button>
                  <Button variant="ghost" size="icon" aria-label={`Eliminar ${p.title}`} onClick={() => setPendingDelete(p)}><Trash2 /></Button>
                </span>
              } />
          ))}
      </Group>

      <ResponsiveSheet open={previewId !== null} onOpenChange={(o) => !o && setPreviewId(null)} className="sm:max-w-3xl"
        title={preview.data?.title ?? ""} description={preview.data?.is_published ? "Publicada" : "Borrador"}>
        {preview.isPending ? <Skeleton className="h-64 rounded-2xl" /> :
          preview.isError ? <ErrorState error={preview.error} /> :
          <Markdown>{preview.data.content_md ?? ""}</Markdown>}
      </ResponsiveSheet>

      <AlertDialog open={!!pendingDelete} onOpenChange={(o) => !o && setPendingDelete(null)}>
        <AlertDialogContent>
          <AlertDialogHeader>
            <AlertDialogTitle>¿Eliminar «{pendingDelete?.title}»?</AlertDialogTitle>
            <AlertDialogDescription>Desaparece del blog y no se puede recuperar.</AlertDialogDescription>
          </AlertDialogHeader>
          <AlertDialogFooter>
            <AlertDialogCancel>Cancelar</AlertDialogCancel>
            <AlertDialogAction variant="destructive" onClick={async (e) => {
              e.preventDefault();
              try { await del.mutateAsync(pendingDelete!.post_id); toast({ title: "Entrada eliminada", tone: "success" }); setPendingDelete(null); }
              catch (err) { toast({ title: "No se pudo eliminar", description: errorMessage(err), tone: "error" }); }
            }}>Eliminar</AlertDialogAction>
          </AlertDialogFooter>
        </AlertDialogContent>
      </AlertDialog>
    </>
  );
}
```
